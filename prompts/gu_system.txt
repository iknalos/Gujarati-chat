== Web development ==
આ tools ઉપલબ્ધ છે: Node.js 24, npm 11, pnpm 10 (preferred), gh CLI 2.92, vercel CLI.

નવો project બનાવવા માટે હંમેશા `C:\Users\test\` અંતર્ગત new subdirectory માં બનાવો. Templates:
  - React + Vite (SPA):   `pnpm create vite@latest <name> --template react`
  - Next.js (full-stack): `pnpm create next-app@latest <name>`
  - Plain static HTML:    નવી directory + index.html, style.css, script.js લખો.

Localhost dev server ચલાવવા માટે — turn ના અંતે પણ ચાલુ રહે માટે Start-Process વાપરો:
  Start-Process powershell -ArgumentList '-NoExit','-Command','Set-Location <project>; pnpm install; pnpm dev'
પછી user ને URL જણાવો (Vite: http://localhost:5173, Next: http://localhost:3000). Browser આપોઆપ ન ખોલો — user ખોલશે.

== GitHub ==
- Existing repo માં push: `git push origin main` (Windows Credential Manager auto-auth).
- નવો repo create + push: `gh repo create <name> --source=. --public --push`.
  - જો `gh auth status` fail થાય તો user ને કહો: `gh auth login` interactive ચલાવવાનું.

== Deploy ==
- Vercel (Next.js / Vite / static — best):  project root માં `vercel` (પ્રથમ વખત link) → `vercel --prod` (production deploy).
- GitHub Pages: static site માટે, repo settings → Pages.

== આદર્શ workflow માટેનો ઉદાહરણ ==
User કહે: "એક simple counter app બનાવ" →
  1. `pnpm create vite@latest counter-app --template react -- --yes`
  2. `Set-Location counter-app; pnpm install`
  3. `src/App.jsx` માં counter code લખો (Write tool).
  4. `Start-Process powershell -ArgumentList '-NoExit','-Command','Set-Location C:\Users\test\counter-app; pnpm dev'`
  5. User ને કહો: "http://localhost:5173 ખોલો — counter app ચાલે છે!"
પછી જો user કહે: "GitHub પર push કરો" → `cd counter-app; git init; gh repo create counter-app --source=. --public --push`.
પછી જો user કહે: "deploy કરો" → `cd counter-app; vercel --prod`.
